Five Peephole Optimization Techniques

1. Redundant Instruction Elimination

Remove unnecessary instructions or simplify operations that do not change the result.

x = y + 0 → x = y

2. Unreachable Code Elimination

Remove statements that cannot execute, such as code after an unconditional jump until the next label.

goto L1
t = a + b // unreachable

3. Control-Flow Optimization

Simplify unnecessary jumps and improve the execution path.

goto L1 → direct transfer to L1

4. Algebraic Simplification & Strength Reduction

Use mathematical identities and cheaper equivalent operations where safe.

x = y * 1 → x = y
x = y - 0 → x = y

5. Use of Machine Idioms

Replace instruction sequences with efficient instructions supported by the target processor.

Example: target-specific increment instruction

DAG Optimization

Detect repeated arithmetic expressions and reuse their computed result.

t1 = a + b
t2 = a + b → t2 = t1

Note: this educational frontend implements basic arithmetic simplification and common-expression reuse. Full unreachable-code, control-flow, and machine-specific optimization require additional compiler logic.

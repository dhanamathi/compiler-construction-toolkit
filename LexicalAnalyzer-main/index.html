Lexical Analysis & Lex/Flex Reference

Compiler Design concepts & equivalent Lex specification (`lexer.l`)

1. What is a Lexical Analyzer (Scanner)?

A Lexical Analyzer is the first phase of a compiler. Its main task is to read the input characters of the source program, group them into meaningful sequences called lexemes, and produce an output stream of tokens for the syntax analyzer (parser).

2. Terminology: Token, Pattern & Lexeme

  • Token: An abstract symbol representing a category (e.g., KEYWORD, IDENTIFIER).
  • Pattern: The rule (regular expression) defining how the token is formed.
  • Lexeme: The actual character sequence in the source code matching the pattern (e.g., int, count, 3.14).

Equivalent Lex / Flex Specification (lexer.l)

Below is the complete Lex specification file included in this project for compiling with flex and gcc:

%{
#include <stdio.h>
int line_no = 1;
%}

%%
\n                      { line_no++; }
[ \t\r]+                { /* Skip whitespace */ }
"//".*                  { printf("Line %d: [Comment] %s\n", line_no, yytext); }
"/*"([^*]|\*+[^*/])*\*+"/" { 
    /* Multi-line comment: update line count */
    for(int i=0; yytext[i]; i++) if(yytext[i]=='\n') line_no++;
    printf("Line %d: [Comment] %s\n", line_no, yytext); 
}
"int"|"float"|"if"|"else"|"while"|"return"|"void"|"char"|"double"|"for" {
    printf("Line %d: [Keyword] %s\n", line_no, yytext);
}
[a-zA-Z_][a-zA-Z0-9_]*  { printf("Line %d: [Identifier] %s\n", line_no, yytext); }
[0-9]+(\.[0-9]+)?       { printf("Line %d: [Constant] %s\n", line_no, yytext); }
\"([^\\\"]|\\.)*\"      { printf("Line %d: [String Literal] %s\n", line_no, yytext); }
"=="|"!="|<=|>=|"&&"|"||"|"++"|"--"|"+="|"-=" {
    printf("Line %d: [Operator (Multi)] %s\n", line_no, yytext);
}
[+\-*/%=<>!&|^~]        { printf("Line %d: [Operator] %s\n", line_no, yytext); }
[()\[\]{},;:?]          { printf("Line %d: [Special Symbol] %s\n", line_no, yytext); }
.                       { printf("Line %d: [Invalid Token] %s\n", line_no, yytext); }
%%

int yywrap() { return 1; }
int main() {
    printf("=== Lexical Analyzer Using Flex ===\n");
    yylex();
    return 0;
}
